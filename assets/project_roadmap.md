# 🚧 공돌이 앱 고도화 프로젝트 로드맵

올려주신 상세한 기능 명세(현장일지 앱 벤치마킹)를 바탕으로, '공돌이' 앱이 앞으로 갖춰야 할 모든 기능을 정리하고 개발 순서를 기획했습니다.

## 📊 1. 데이터베이스(DB) 대공사 (1단계)
기존의 단순한 일당 기록을 넘어, 세금, 품수, 경비 등을 모두 담을 수 있도록 DB를 확장합니다.
- **프로필(설정) 확장**: 내 직종(목수, 타일 등 8종), 계좌번호, 기본 일당, 3.3% 공제 기본값 설정 추가
- **작업 기록(현장) 확장**: 작업 내용, 품수(0.5품, 1품 등), 3.3% 공제 여부, 경비(식대/자재비), 달력 표시 색상 추가
- **정산 시스템 추가**: 정산(입금) 내역 기록, 미수금 관리 상태 추가

## 🎨 2. 하단 탭바 및 핵심 UI 개편 (2단계)
현재의 슬라이드 메뉴 방식을 버리고, 하단 고정 탭(Bottom Navigation) 방식으로 전면 개편합니다.
- **[달력] 탭**: 한 달 동안의 작업일, 총 일당, 미수금, 주간 합계, 날짜별 점(색상) 표시
- **[현장] 탭**: 등록된 현장 목록, 새 현장 추가, 기간별 현장 묶어보기
- **[정산] 탭**: 이번 달 총 일당, 미수금 현황, 수동 정산(입금 완료) 처리 기능
- **[통계] 탭**: 월별/연간 수입 추이 그래프, 평균 일당, 엑셀/PDF 내보내기(프리미엄)
- **[설정] 탭**: 프로필 수정, 테마(라이트/다크), 기본 단가 세팅, 고객센터(문의하기)

## 🏗️ 3. 핵심 기능 구현 (3단계)
- **작업 추가 폼**: 날짜 다중 선택, 품수 계산, 세금(3.3%) 자동 계산 로직 적용
- **오늘 한 일 (메모)**: 메인 화면에서 당일 작업 내역을 빠르고 길게 적을 수 있는 전용 메모장
- **팀 기능 연동**: 팀 만들기, 초대 코드로 가입, 팀원 간 현장 데이터 공유

## ✨ 4. 프리미엄 & 부가 기능 (4단계)
- **종합소득세 예상 계산기**: 1년간의 수입을 바탕으로 내년 5월 종소세 예상치 계산
- **캘린더 구독 (동기화)**: 아이폰/구글 캘린더 앱과 내 공돌이 작업 일정 자동 연동
- **인건비 명세서 PDF**: 현장별로 깔끔한 명세서를 PDF로 뽑아서 소장이나 반장에게 전송
- **AI 현장 브리핑**: 작성한 메모와 현장 데이터를 분석해주는 AI 리포트
